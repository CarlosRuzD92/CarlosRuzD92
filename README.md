### 🧩 Asistente Diario – Backend distribuido con microservicios

Sistema distribuido basado en microservicios independientes.

🔗 Repositorios:
- [User Service](https://github.com/CarlosRuzD92/daily-assistant-user-service)  
- [Notes Service](https://github.com/CarlosRuzD92/daily-assistant-notes-service)

Aplicación web con backend en Laravel orientada a la gestión de usuarios, productos y pedidos con un frontend básico en HTML.

- Desarrollo de API REST con PHP y Laravel.

- Gestión de productos, categorías y búsqueda con filtros.
- Lógica de pedidos (creación e historial), persistencia en MySQL y validación de endpoints con Postman.
